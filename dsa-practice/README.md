# DSA Practice Roadmap

This repository tracks my DSA learning roadmap (Python, NeetCode 150 + CSES + Codeforces), organized phase by phase.

## Repository Structure

```
dsa-practice/
  ├── template.py       # Fast-IO starter script for competitive programming & problem solving
  ├── tracker.md         # Daily problem log and spaced repetition tracker (+3d / +7d / +21d)
  ├── pattern-cards/     # Concept summaries & reusable templates per pattern (e.g., two-pointers.md)
  ├── phase0/ ... phase7/# Roadmap phases
  │     ├── notes.md     # Daily 3-line write-ups (Pattern, Key trick, Mistake)
  │     └── solutions/   # Problem solution scripts (.py)
  └── README.md          # Overview and workflow guidelines
```

## Daily Problem Logging Rules

For every problem in `phaseN/notes.md`, record a concise 3-line entry:
1. **Pattern:** (e.g., Sliding Window / Monotonic Stack / Topological Sort)
2. **Key trick:** The single critical insight or invariant.
3. **Mistake:** Why you were stuck or what edge case tripped you up.
